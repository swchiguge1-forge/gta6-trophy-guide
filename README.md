# GTA VI Trophy Guide

Entry for make.fun `gta6-trophy-guide-01`: a complete trophy guide for
Grand Theft Auto VI on PlayStation 5 — all 55 trophies, each with a
step-by-step guide, missable warnings and time notes.

Features: platinum roadmap in 4 stages, filters by grade / chapter / kind /
missable, text search, spoiler-hiding setting, and a progress checklist
(saved locally, with export/import). Runs entirely offline in the browser.

## Run

```sh
node serve.ts
# open http://localhost:8080
```
